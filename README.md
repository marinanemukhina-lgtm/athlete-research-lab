# Athlete Research Lab

Open-source research prototype for comparative sports science, nutrition, powerlifting training, and evidence-labelled clinical scenarios.

**Status:** early prototype; not a validated medical decision-support system. Research and clinical statements require independent review.

## Local use

Open `index.html` in a browser. The application is a static, dependency-free HTML prototype.

## Roadmap

- Independently verify clinical source material and national differences.
- Add automated nutrition calculations and training logs with tests.
- Improve accessibility and mobile experience.
- Add privacy-safe storage and documented data provenance.

## Disclaimer

Educational research tool. It does not diagnose, prescribe medication, or replace a licensed clinician.
